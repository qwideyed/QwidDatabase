How This Works on GitHub Pages

Client-side static hosting vs. Full backend requirements

1. What works 100% natively on GitHub Pages

Because GitHub Pages is a static host (no Node.js/Python server), any direct media URL (like .mp4, .mp3, .webm) or permissive CDN video downloads directly inside your browser via standard Blob streaming.

2. Why platforms like YouTube / TikTok block direct browsers

Modern video sites use CORS (Cross-Origin Resource Sharing) locks and separate adaptive streams (.m3u8 / HLS). The browser cannot merge audio and video tracks without an intermediary FFmpeg demuxer.
